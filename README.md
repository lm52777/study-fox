# 🦊 伴学小狐 (Study Fox)

一只爱学习的小狐狸 —— **儿童学习陪伴网页应用**。纯静态、免费、无需安装登录,手机和电脑打开就能用。

> 🔗 在线体验:https://lm52777.github.io/study-fox/

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 📜 古诗 | 8 首经典古诗:逐句点读、全诗朗读、译文、小知识,每首配一道小测验 |
| 🧮 口算闯关 | 三档难度(10 以内 / 100 以内 / 乘法表),10 题一轮,答对挣星星 |
| 🀄 识字卡 | 12 个基础汉字,翻卡看拼音、组词、例句,带朗读 |
| 📖 成语故事 | 狐假虎威、守株待兔、拔苗助长、画蛇添足,带寓意讲解 |
| 💬 语音聊天 | 内置小狐狸机器人:讲笑话、脑筋急转弯、背诗、出题考你;Chrome/Edge 支持语音输入 |
| ⭐ 奖励系统 | 答题挣星星,集星解锁贴纸(本地保存,不传服务器) |
| 👀 护眼卫士 | 学习 20 分钟自动提醒休息,保护小眼睛 |
| 🔉 朗读语速 | 0.8x ~ 1.3x 可调 |

## 🎨 设计

- 手机优先的单页应用,零依赖、零构建:原生 HTML / CSS / JavaScript
- 配色基于经过色盲友好校验的调色板(蓝/橙对比度全部通过校验)
- 大按钮、大字号、圆角卡片,适合 5~10 岁小朋友使用
- 朗读使用浏览器自带中文语音合成(TTS),无需任何后端

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可,无需服务器。

## 📁 目录结构

```
study-fox/
├── index.html   # 页面结构(所有界面)
├── style.css    # 设计系统与样式

└── README.md
```
